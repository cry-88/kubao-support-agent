# 项目约定 · 哭包智能客服

## 部署与远程操作（用户 2026-10-22 要求）

- 需要部署或操作远程 Linux 云服务器时，自动走 SSH MCP（run_command / sftp / 文件读写）。
- **任何 shell 命令、高危操作，执行前必须把完整命令贴给用户审核，确认后才跑**；禁止直接执行危险指令。
- 部署本项目时的注意事项：Node ≥18、`node server.js`、监听 `$PORT` 且绑定 0.0.0.0；数据在 `data/store.json`（需可写、不可对外暴露）；首次启动用环境变量 `CS_ADMIN_CODE` / `CS_AGENT_CODE_1/2` 设定口令。
